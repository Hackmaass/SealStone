## P09 Attack Lab (2026-10-11)
- `/attack-lab`: 12 attacks + 1 contrast, each a REAL call from the sandbox accounts (#3 attacker, #4 client, #5 provider, #6 arbiter). Engine and catalogue are React-free in `lib/attacks.ts` (steps are setup / attempt / check); `ui/AttackRow.tsx` + `pages/AttackLab.tsx` draw it like the prototype (stars, cursor row, stamped verdicts, red-tinted contrast).
- **Deviation from the prompt (on purpose):** instead of two shared sandboxes, EVERY attack deploys its own fresh 3-milestone vault. Rows are independent (Run works alone), "Run all" is trivially idempotent (it also clears the table first), and no row can be fooled by a previous row's leftovers. The demo vaults are never touched; the e2e proves it by comparing the seeded vault's events, milestone state, balance and code before and after 39 sandbox runs.
- Honesty rules: three outcomes (pass = matched expectation, FAILED = the contract did something else, Lab error = the lab could not finish; only pass counts as blocked). The score is computed from the results, never hard-coded. Refused calls are shown as "refused before it was mined: no transaction, no gas". The re-entrancy row sends an explicit gas limit (estimation finds the minimum gas, where a re-entry could fail by running out of gas instead of by the guard) and asserts the guard's own error (`ReentrancyGuardReentrantCall` decoded from `lastRevertSelector`), attempts >= 1, blocked == attempts, succeeded == 0, the payout is exactly the 1.000 ETH owed and nothing remains owed. The force-send row asserts surplus == 0.300 ETH, reconcile ok, and that the attacker's withdraw is `NothingToWithdraw`. The contrast row computes its own shortfall (NaiveEscrow has no reconcile) and is a FAIL ("Did not reproduce") if nothing is drained.
- "Proven in tests" names are literal strings; `lib/attacks.test.ts` reads `contracts/test/**` and fails if any cited name is missing. The four booklet rows are the four exact required test names.
- Raw errors now name states: `InvalidMilestoneState(index: 0, actual: Released)` instead of `actual: 3` (also on the vault screen).
