Wallet not showing up? Checklist and diagnostics
  1. Open this exact page in the same browser profile where the wallet extension is installed (not a private window, unless the extension is allowed there).
  2. In the browser's extensions page, make sure the extension is enabled and its site access allows this page (set it to "On all sites"), then reload this page.
  3. Unlock the wallet and press Rescan.
  4. If several wallet extensions are installed, disable the others for a moment, or pick the right one in the list.
  5. If it still isn't listed, copy the diagnostics below and send them to whoever is helping you.
